【可用指令】（不区分大小写，首尾空格会被忽略）
  help / 帮助            查看本帮助
  look / 看              观察当前场景
  go 方向 / 走 方向       移动：north south east west up down（或 n s e w u d / 北南东西上下）
  status / 状态           查看角色状态面板
  map / 地图              查看整个校园地图
  bag / 背包              查看背包
  talk 名字 / 对话        与场景中的 NPC 交谈
  search / 搜             搜索当前场景，可能找到物品或印章
  quiz / 答题             抽一道校园谜题
  answer 答案 / 答        回答当前谜题
  hint / 提示             查看当前谜题的提示
  study / 自习            刷题：消耗体力，换取学分
  rest / 休息             在宿舍 / 食堂 / 校医院恢复体力
  fight / 挑战            与当前场景的对手对决
  attack / defend / flee  战斗中的进攻、防守、逃跑
  use 物品 / 用           使用背包里的物品
  quit / 退出             退出游戏
